Using Claude Code and Codex with WordPress

Connect your agent to WordPress Studio, then ask it to work on a local site.

  1. Start a local site. Download WordPress Studio, then create a site or import one you already have.
  2. Connect your agent. In WordPress Studio, open Settings → Agents and install the plugin for Claude Code or Codex. Start a new agent session and ask it to list your sites. For another MCP client, connect it to studio mcp.
  3. Build and review. Ask your agent to change a page, build a theme or install a plugin. Review the work locally, then share a preview link for feedback.

Choosing a local development tool? Compare WordPress Studio and LocalWP.
