Local WordPress development with WordPress Studio

Create a site in the app or the CLI and work on it on your computer.

WordPress Studio uses native PHP and SQLite by default, without Docker or a separate database server. You can use MySQL if your project needs it.

Moving from Local? Export your site as a ZIP and import it into WordPress Studio. You can share a preview for feedback, then publish to WordPress.com or Pressable, or publish a static copy to Spacefast.

Use Claude Code, Codex and other AI agents with WordPress, or download WordPress Studio for macOS, Windows or Linux.
