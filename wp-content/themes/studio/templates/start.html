Using the command line?

In a terminal, open the folder you want your site in, run this, and describe the site you want:

studio code

No studio command yet? Install the CLI on macOS or Linux:

curl -fsSL https://wordpress.studio/install.sh | bash

Or on Windows, in PowerShell:

irm https://wordpress.studio/install.ps1 | iex
