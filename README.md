# Docs port: Blume vs WordPress screenshots

Side-by-side screenshots for the pull request that ports wordpress.studio/docs from Blume to WordPress
(Automattic/studio-website). `index.html` shows every page at 1440px and 390px, light and dark, Blume on
the left and WordPress on the right, plus the interactions (search, theme toggle, code copy, chat menu,
scroll-spy, drawer, zoom). Open it locally; the images are in `shots/` and `interact/`.

This branch holds only these files and can be deleted once the pull request is reviewed.
